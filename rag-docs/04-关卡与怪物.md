# 关卡与怪物设计

## 波次阶段


| 阶段       | 时间占比      | 刷怪间隔 | 同屏上限 |
| ---------- | ------------- | -------- | -------- |
| 初期 early | 0%~22%        | 800ms    | 15       |
| 中期 mid   | 22%~55%       | 500ms    | 30       |
| 后期 late  | 55%~最后1分钟 | 350ms    | 50       |

- 阶段切换时屏幕中央提示：初期·小怪试探 / 中期·精英现身 / 后期·群敌围攻
- 游戏最后 1 分钟不再刷小怪
- 精英怪只在 mid/late 刷，early 不出精英；精英同屏上限 15

## 各关怪物构成

- L1 血色禁地：妖虫/魔蝠/魔修/妖狐，精英仅妖将
- L2 坠魔谷：魔蝠/魔修/妖狐/石傀，精英加魔兵狂战士
- L3 幽冥暗渊：魔修/妖狐/石傀/小史莱姆，精英加魔骑突阵，可进化武器
- L4 虚空雷狱：妖狐/石傀/小史莱姆/史莱姆，精英加魔甲守卫，可进化武器
- L5 九天仙庭：石傀/小史莱姆/史莱姆/赤鬃猪，全部5种精英，可进化武器

## Boss出场时间

- L1 王婵：11:00 出场
- L2 古魔：14:00 出场
- L3 元刹圣祖：16:30 出场
- L4 鱼店长：19:30 出场
- L5 真仙马良：22:00 出场
- Boss 出场后刷怪放缓，Boss 死亡即通关

## 血包回复

- 前期（0~40% 游戏时间）：+20
- 中期（40%~75%）：+30
- 后期（75%~100%）：+50

## 升级与经验

- 每关目标等级 = 关卡时长(分钟) + 2（L1 13分钟→lv15，L5 25分钟→lv27）
- 后期关卡经验倍率更高：L1/L2 ×0.6，L3 ×1.1，L4 ×1.45，L5 ×1.95
- 升级所需经验按 1.3 倍逐级增长
