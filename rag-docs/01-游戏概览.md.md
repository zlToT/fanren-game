# 《凡人·秘境苟道》游戏概览

## 游戏类型

横版生存割草类游戏（类吸血鬼幸存者）。玩家在限定时长内击杀怪物、升级武器，
最终击败关底Boss即通关。共 5 个关卡。

## 五个关卡一览


| 关卡 | 名称     | 时长   | Boss     | 目标等级 |
| ---- | -------- | ------ | -------- | -------- |
| L1   | 血色禁地 | 13分钟 | 王婵     | lv15     |
| L2   | 坠魔谷   | 16分钟 | 古魔     | lv18     |
| L3   | 幽冥暗渊 | 19分钟 | 元刹圣祖 | lv21     |
| L4   | 虚空雷狱 | 22分钟 | 鱼店长   | lv24     |
| L5   | 九天仙庭 | 25分钟 | 真仙马良 | lv27     |

## 核心操作

- 武器自动攻击，升级时五选一强化
- Q键：切换青元剑诀的剑式（护身/追击/分组追击）
- E键：释放辟邪神雷（清屏大招，25s充满，CD 10s）
- 瞬身：CD 8s，无敌 2s

## 玩家基础属性

- 初始血量 300，每级 +30
- 基础攻击力 30，每级 +10
- 玩家对魔修阵营伤害 +50%
