# 武器系统设计方案

## 通用规则

- 每把武器最高 5 级，升级通过升级五选一获取
- 等级满了可以进化（前两关不能进化），进化后伤害大幅提升
- 所有武器伤害公式集中在 `calculate.js`
- 全局伤害倍率 `game.dmgMul`（被动"伤害提升"每级 +15%）乘在最后

---

## 1. 青元剑诀（飞剑）

- **初始**：8 把飞剑环绕
- **升级**：每级 +7 把飞剑（Lv5 达 36 把），+5 基础伤害，+2 护身半径
- **剑式**（Q 键切换）：
  - 🛡 **护身**：环绕身周
  - ⚔️ **追击**：自动追踪最近敌人
  - 🗡 **分组追击**：按扇形分组，CD 一到整组全部出击
- **伤害公式**：`(10 + lv*5 + playerAtk) * dmgMul`
- **进化 → 青元剑阵**：飞剑增至 72 把，伤害 ×1.6，护身半径 78
- **暴击**：被动"飞剑暴击"每级 +15% 暴击率（初始 10%），暴击飘字红色放大
- **暴伤**：被动"飞剑暴伤"每级 +15%（初始 130%）
- **冰冻**：被动"飞剑冰冻"每级 +10% 概率，命中冰冻 1s（蓝色 ❄️ buff）

## 2. 噬金虫

- **初始**：1 只
- **升级**：每级 +1 只（Lv5 达 5 只）
- **移动速度**：追击 7.2 px/frame，待机 4 px/frame
- **攻击**：每只虫独立 200ms 攻击间隔，飞行途中碰到其他敌人造成半伤
- **伤害公式**：`(50 + lv*10 + playerAtk) * dmgMul`，碰撞半伤 ×0.5
- **进化 → 噬金虫海**：伤害 ×2，体型放大 1 倍

## 3. 九霄神雷

- **初始**：1 处落雷 1 道，CD 8s
- **升级**：
  - Lv3：2 处落雷
  - Lv5：3 处落雷每处 3 道
- **范围**：100×100 px
- **伤害公式**：`((30 + lv*12)*3 + playerAtk*2) * dmgMul`，对魔修阵营 ×1.5
- **进化 → 九霄神雷·寂灭**：3 处 × 3 道，范围 150×150，伤害 ×2

## 4. 摄魂幡（环绕）

- **初始**：1 个环绕
- **升级**：每级 +1 个（Lv5 达 5 个），+5 环绕半径
- **攻击**：300ms tick
- **伤害公式**：`(15 + lv*15 + playerAtk*0.5) * dmgMul`
- **进化 → 百鬼夜行**：双环环绕（内圈 10 + 外圈 5），体型 ×3，速度 ×2.5

## 被动技能


| 被动     | 满级 | 效果                         |
| -------- | ---- | ---------------------------- |
| 移速提升 | 5    | 每级 +0.5 移动速度           |
| 生命上限 | 5    | 每级 +100 上限并回复 50      |
| 伤害提升 | 5    | 每级 +15% 所有伤害           |
| 冷却缩减 | 5    | 每级 -10% 冷却               |
| 飞剑暴击 | 3    | 每级 +15% 暴击率（初始 10%） |
| 飞剑暴伤 | 3    | 每级 +15% 暴伤（初始 130%）  |
| 飞剑冰冻 | 3    | 每级 +10% 冰冻概率，冰冻 1s  |

## 辟邪神雷（E 键）

- **初始**：雷源满
- **充能**：25s 充满，击杀怪物增加充能，CD 10s
- **效果**：
  1. 清屏弹幕
  2. 中心范围：`(200 + playerAtk*5) * dmgMul`，对魔修 ×1.5
  3. 全屏扩散圈：一段的 50%
