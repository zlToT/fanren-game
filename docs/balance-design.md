# 数值平衡设计方案

记录诊断结论 + 每一次数值调整，方便回溯。

---

## 诊断基线（2026-10-18）

### DPS 估算（理论值）

| 武器 | Lv3 中期 DPS | 进化后 DPS |
|---|---|---|
| 青元剑诀（22 把） | ~560 | ~3400（72 把剑阵） |
| 噬金虫（3 只） | ~750 | ~1500（×2） |
| 九霄神雷（2 处×1 道） | ~70 | ~140 |
| 摄魂幡（3 幡） | ~500 | ~4200（15 幡） |
| 辟邪神雷 E（20s） | ~29 | — |

> 注：实测 Boss 战感受是"打不动"，不是"秒杀"。理论 DPS 偏高的原因：飞剑 30% 命中假设过于乐观、敌人会移动躲开。实际有效 DPS 大概是理论值的 1/3 ~ 1/2。

### 生存压力
- 玩家 hp：150 + (lv-1)*10 → L1 结束 ~290
- 同屏 20 怪贴身承伤 ~165 DPS，2 秒就死
- 瞬身 CD 8s / 无敌 2s，覆盖率 25%，不够用

## 调整记录

### 2026-10-18 第一轮

| 项 | 旧值 | 新值 | 原因 |
|---|---|---|---|
| 玩家每级血量 | +10 | **+25** | 生存压力不够，同屏怪贴身 2 秒就死 |
| 噬金虫 hitT | 500ms | **200ms** | 虫子 DPS 太低（5 只才 750），提频率 |
| 九霄神雷单发 | base 30+lv*12 | **×3**（base 90+lv*36） | DPS 70 几乎可忽略，单发提 3 倍 |
| 怪物 HP 时间成长 | 无 | **每分钟 +5%**（从 Boss 出场后开始累计） | 后期纯割草，需要压力曲线抬升 |
| early 刷怪间隔 | 420ms | **800ms** | 玩家刚出门 dps 太低，420ms 刷不动 |
| early 同屏上限 | 32 | **15** | 同上 |
| mid 刷怪间隔/上限 | 300ms / 55 | **500ms / 30** | 压力曲线过渡更平滑 |
| late 刷怪间隔/上限 | 220ms / 85 | **350ms / 50** | 同上 |
| 特殊精英刷新时机 | `time < dur*0.5` 就随机刷 | **`time > dur*0.22` 才刷** | 之前 early 阶段偷偷刷精英，新手期压力过大 |

| orbit 基础伤害 | 5+lv*5 | **15+lv*15** | 环绕 dps 偏弱，提一档对齐其他武器 |

**影响链**：
- Boss hp ×16~40 → 雷源积攒变慢（打怪掉雷源 3%/只，Boss 40%）→ Boss 战期间雷源主要靠 Boss 自己掉，E 技能在 Boss 战中约能放 6~8 次。
- 怪 hp ×4 → 玩家 TTK 从 0.07s → 1.5s 目标值，但同屏怪压力不变（数量/刷新率没动）。
- 怪 dmg ×8 → 玩家承伤从"50 次才死"变成"9 次"，需要走位。
- hpMul 1.6→2.1（L5）→ 后期怪额外 +30% 血，配合时间成长 +5%/min。

### 2026-10-18 第五轮（体验微调）

| 项 | 旧值 | 新值 | 理由 |
|---|---|---|---|
| 血包回复 | 固定 +20 | **前期 +50 / 中期 +75 / 后期 +100**（按时间占比 40%/75% 分界） | 后期血厚了血包也要跟得上 |
